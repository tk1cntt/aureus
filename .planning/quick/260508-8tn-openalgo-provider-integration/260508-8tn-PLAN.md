## Assumptions

- Giữ MT5 native execution là default để không đổi hành vi hiện tại.
- OpenAlgo chỉ chạy khi bật input riêng, tránh tự gửi lệnh sang OpenAlgo trong runtime hiện tại.
- Mapping tối thiểu: `direction` -> action `BUY`/`SELL`, `volume` -> integer quantity, `symbol`/`comment` -> OpenAlgo symbol/strategy fallback, `order_type`/`price` -> OpenAlgo price type/price params.
