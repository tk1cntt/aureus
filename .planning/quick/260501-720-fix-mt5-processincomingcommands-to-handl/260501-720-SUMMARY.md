# Quick 260501-720 Summary

Đã sửa `ProcessIncomingCommands()` để một lần `g_socket.Receive()` có thể tách và xử lý lần lượt nhiều JSON object hoàn chỉnh, tránh bỏ sót các lệnh order/command nối liền trong cùng buffer.

## Thay đổi chính

- Tách dispatch command hiện hữu sang `ProcessSingleCommand(const string &raw)` để mỗi JSON object độc lập đi qua cùng handler cũ.
- `ProcessIncomingCommands()` scan raw buffer bằng brace-depth, có trạng thái `inString` và `escaped`, nên không cắt sai khi braces nằm trong JSON string.
- Giữ nguyên semantics của `ExecuteOpenOrder`, `ExecuteCloseOrder`, request handlers, dedup, ACK/NACK và provider-local unsupported-symbol ignore.
- Sửa cấu trúc điều kiện `REQUEST_BACKFILL_COUNT`/`REQUEST_ORDERS` để mỗi command được dispatch độc lập đúng loại thay vì phụ thuộc nhầm vào điều kiện trước đó.
