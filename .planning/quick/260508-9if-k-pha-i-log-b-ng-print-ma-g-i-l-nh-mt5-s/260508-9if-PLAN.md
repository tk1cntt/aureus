# Quick Task 260508-9if Plan

## Goal

Đổi phần OpenAlgo trong `mql5/AureusProvider_v2.mq5` để gửi lệnh sang OpenAlgo bằng `PlaceOrder(...)` giống `mql5/OpenAlgo.mq5`, thay vì chỉ `Print` hoặc tự build wrapper riêng. MT5 vẫn mở lệnh như cũ trước, OpenAlgo chỉ nhận lệnh sau native `ORDER_OPENED`.

## Assumptions

- User nói “K phải log bằng Print” nghĩa là không chỉ ghi log local; phải gọi OpenAlgo API bằng `PlaceOrder(...)`.
- Vẫn giữ yêu cầu trước: MT5 native không bị gián đoạn. Vì vậy `PlaceOrder(...)` chạy sau native `PushOrderOpened(...)`, không chạy trước `OrderSend()`.
- `PlaceOrder(...)` trả `void`; vì vậy kết quả OpenAlgo không được dùng để đổi trạng thái gateway.

- No native MT5 validation/order execution branch changes.
