# Quick Task 260424-1d1 Summary

## Objective
Di chuyển logic `journal.on_strategy_match(...)` từ `main.py` sang `dispatch_order` tại nhánh `ORDER_OPENED`, đồng thời preserve `trace_id` để journal liên kết đúng strategy-event với order-opened.

## Changes

### 1) `services/aureus-trader/main.py`
- Bổ sung `order_cmd["strategy_event"] = event` để truyền ngữ cảnh strategy sang dispatcher.
- Xóa gọi trực tiếp `asyncio.create_task(journal.on_strategy_match(event))` sau enqueue.

### 2) `services/aureus-trader/dispatcher.py`
- Trong nhánh `if final.get("type") == "ORDER_OPENED"`:
  - Lấy `strategy_event` từ `order`.
  - Sao chép payload strategy và bổ sung `trace_id` nếu thiếu.
  - Gọi `await self.journal.on_strategy_match(strategy_payload)` trước `on_order_opened`.
  - Giữ nguyên flow enrich `final` và `await self.journal.on_order_opened(final)`.

### 3) `services/aureus-trader/tests/test_dispatcher.py`
- Mở rộng `DummyJournal`/`NoopJournal` với `on_strategy_match`.
- Thêm test:
  - `test_dispatch_order_calls_strategy_match_on_order_opened_with_trace_id`
  - `test_dispatch_order_does_not_call_strategy_match_when_not_order_opened`
