# Phase 36 Plan: Fix BUY/SELL direction from strategy settings not name

## Problem Statement

Hiện tại `TemplateStrategy` đang suy luận direction (BUY/SELL) từ tên strategy:

```python
# template.py dòng 45-48
self.direction = self.trade_execution.get("direction")
if not self.direction:
    self.direction = "SELL" if "BEAR" in self.name.upper() else "BUY"
```

**Vấn đề:**
- Strategy tên "TREND_CONT_BULL" luôn BUY dù config có thể muốn SELL
- Strategy tên "ORDER_FLOW_BEAR" luôn SELL dù setting có thể khác
- Không thể cấu hình direction độc lập với tên strategy
- Direction không rõ ràng, dễ gây nhầm lẫn khi maintain

## Solution Design

### 1. BẮT BUỘC direction trong trade_execution config

- Bỏ fallback vào tên strategy
- Nếu không có `direction` trong `trade_execution` → raise `ValueError`
- Validate direction là "BUY" hoặc "SELL" (case-insensitive)

### 2. Migration seed strategies

- Cập nhật `seed_strategies.py` để thêm `direction` field vào mọi `trade_execution`
- BULL strategies → `"direction": "BUY"`
- BEAR strategies → `"direction": "SELL"`

### 3. Update tests

- Thêm `direction` vào config của tất cả test cases
- Thêm test case validate direction bắt buộc
- Thêm test case direction invalid

## Task Breakdown

### Task 1: Sửa TemplateStrategy.__init__ (d=1 impact)

**File:** `services/aureus-signal/engine/strategies/template.py`

**Thay đổi:**
```python
# TRƯỚC (dòng 45-48):
self.direction = self.trade_execution.get("direction")
if not self.direction:
    self.direction = "SELL" if "BEAR" in self.name.upper() else "BUY"

# SAU:
direction = str(self.trade_execution.get("direction", "")).strip().upper()
if direction not in ("BUY", "SELL"):
    raise ValueError(
        f"Strategy '{self.name}': 'direction' must be 'BUY' or 'SELL' in trade_execution config. "
        f"Got: {self.trade_execution.get('direction')!r}"
    )
self.direction = direction
```
