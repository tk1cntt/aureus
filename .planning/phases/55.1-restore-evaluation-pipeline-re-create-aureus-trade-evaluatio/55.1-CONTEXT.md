<decisions>
## Implementation Decisions

### Schema & Migration (carried from Phase 55)
- **D-01:** Giữ nguyên schema đã định nghĩa trong phase 55 - không thay đổi thiết kế
- **D-02:** Evaluation schema bám theo khóa/quan hệ của Trade Execution Journal (trade_journal_id FK)
- **D-03:** Unique constraint trên `(trade_journal_id, score_version)` để hỗ trợ versioning/recompute
- **D-04:** JSONB fields cho score_breakdown và weights_snapshot

### Pipeline Trigger (carried from Phase 55)
- **D-05:** Trigger persist evaluation bắt đầu **sau ORDER_OPENED thành công**
- **D-06:** Payload validation với `EVAL_PAYLOAD_MISSING_CORE_FIELDS` fail-fast
- **D-07:** Idempotency via `ON CONFLICT (trade_journal_id, score_version) DO NOTHING`

### Recompute (carried from Phase 55)
- **D-08:** Append-only inserts - không overwrite version cũ
- **D-09:** Canonical lineage: journal → snapshot → fallback

### Runtime Evidence (new for Phase 55.1)
- **D-10:** Phải có artifact `55.1-*-runtime-evidence.json` với `tables_ok=true`, `indexes_ok=true`, `latest_rows_ok=true`

### What to Restore
- **Từ migration 55-01:** `aureus_trade_evaluations` table với cột lineage + constraints
- **Từ journal.py 55-02:** INSERT path trong `on_order_opened`
- **Từ recompute 55-03:** Append-only logic với `is_current` flip
- **Từ runtime gate 55-07:** Evidence verification script
