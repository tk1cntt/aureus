### The CRITICAL Gap: Post-Trigger Stall ❌

After a strategy successfully triggers:

```python

    state_obj,
    triggered_t=bar_t,  # ← Sets triggered_t to trigger timestamp
    ...
)

# _reset_sequence_state sets:

    "current_step_index": 0,  # ← Reset to 0
    "triggered_t": bar_t,     # ← Set to trigger time
}
```

**On next candles:**

```python
# template.py line 254-260
if triggered_t > 0 and latest_time <= triggered_t:
    continue  # ← SKIP ALL EVENTS with t <= triggered_t
```

**Auto-reset check (Plan 01):**
```python

    # Auto-reset NEVER fires
```

**Result:** ALL events skipped → SEQUENCE_NOT_MATCHED → permanent stall → only restart fixes it

**Impact:** HIGH (fixes root cause of permanent death)

#### Implementation

**File:** `services/aureus-signal/engine/strategies/template.py`

**Location 1:** After line 149 (`internal_candle_counter += 1`), BEFORE global timeout check

```python
# --- Phase 39.1 Fix Stage 1: Clear triggered_t after timeout to prevent post-trigger stall ---
# This fixes the gap where auto-reset (Plan 01) only handles mid-sequence stalls
# but not post-trigger stalls (current_step_index == 0 after trigger)
if triggered_t > 0 and current_step_index == 0:
    trigger_counter = state.get("_trigger_candle_counter", 0)
    candles_since_trigger = internal_candle_counter - trigger_counter
    TRIGGER_TIMEOUT_CANDLES = 10  # Configurable later per strategy

    if candles_since_trigger > TRIGGER_TIMEOUT_CANDLES:
        logger.info(
            f"[{symbol}] [{self.name}] [trigger_timeout] "
            f"Clearing triggered_t={triggered_t} after {candles_since_trigger} candles "
            f"to prevent post-trigger stall"
        )
        triggered_t = 0
        # Reset counter to current value so timeout doesn't fire again immediately
        state_obj.strategy_progress[self.name]["_trigger_candle_counter"] = internal_candle_counter
```

### Stage 3: Health Monitoring & Self-Recovery (LONG-TERM) 🏥

**Goal:** Detect and recover from any future stall patterns automatically  
**Risk:** MEDIUM (adds new subsystem)  
**Impact:** HIGH (prevents all future silent failures)  
**Time:** ~3-4 hours  
**Prerequisite:** Stages 1 & 2 must be stable

#### Implementation

**File:** `services/aureus-signal/engine/strategy_executor.py`

**Add to main executor loop:**

```python
# Health monitoring state
last_trigger_time = time.time()
stall_detection_enabled = True

while True:
    # ... existing main loop ...

    if strategy_triggered:
        last_trigger_time = time.time()

    # Periodic health check (every 60 seconds)
    if time.time() - last_trigger_time > 3600:  # 1 hour threshold
        if stall_detection_enabled:
            logger.warning(
                f"[EXECUTOR] [HEALTH] No strategy triggers in {int(time.time() - last_trigger_time)}s. "
                f"Possible stall detected. Checking strategy_progress state..."
            )

            # Log diagnostic info for debugging
            for symbol, strategies in executor_strategy_progress.items():
                for strat_name, progress in strategies.items():
                    triggered_t = progress.get("triggered_t", 0)
                    current_step = progress.get("current_step_index", -1)
                    if triggered_t > 0:
                        logger.warning(
                            f"[EXECUTOR] [HEALTH] [{symbol}] {strat_name}: "
                            f"triggered_t={triggered_t}, current_step={current_step}"
                        )

            # Self-healing: force clear triggered_t for all strategies
            # This is safe because Stage 1 timeout mechanism already does this per-candle
            # This is just a belt-and-suspenders safety net
            for symbol in symbols_list:
                if symbol in executor_strategy_progress:
                    for strat_name in executor_strategy_progress[symbol]:
                        progress = executor_strategy_progress[symbol][strat_name]
                        if progress.get("triggered_t", 0) > 0:
                            logger.info(
                                f"[EXECUTOR] [HEALTH] [{symbol}] {strat_name}: "
                                f"Force clearing triggered_t as self-healing measure"
                            )
                            progress["triggered_t"] = 0
                            progress["_trigger_candle_counter"] = progress.get("internal_candle_counter", 0)

            last_trigger_time = time.time()  # Reset timer after self-healing
```

**Benefits:**

1. **Early warning:** Logs when no triggers for 1+ hour
2. **Diagnostics:** Shows which strategies are stuck and why
3. **Self-healing:** Force clears stuck state without restart
4. **Observability:** Can integrate with monitoring/alerting later
