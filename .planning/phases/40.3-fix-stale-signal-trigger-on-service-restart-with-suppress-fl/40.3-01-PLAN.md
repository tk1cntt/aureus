# Plan 01: Implement Suppress Flag for Startup Signal Suppression

## Objective

Thêm `_signal_suppressed` flag vào live_engine.py để chặn signals và strategies trigger trên stale data khi service restart. Flag set True sau snapshot restore, reset False khi nhận candle real-time đầu tiên từ gateway.

## Scope

- 1 file: `live_engine.py`
- ~8 dòng code thêm vào
- Không sửa bất kỳ file nào khác

## Risk Mitigation

- Dùng `getattr(state, "_signal_suppressed", False)` everywhere — nếu attribute không tồn tại, mặc định False (không chặn gì) → fail-safe
- Không sửa state.py `to_dict()` — flag không serialize → không ảnh hưởng snapshot/restore
- Không sửa signal calculators — suppression ở publish layer → zero ripple effect
