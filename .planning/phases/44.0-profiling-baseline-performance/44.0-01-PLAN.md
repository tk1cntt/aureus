- `services/aureus-signal/engine/state.py` (to see state structure for adding profiling counter)
</read_first>

<action>
Modify `execute_signals_for_candle()` in `live_engine.py` (lines 85-112) to:

1. Add `import time` at the top of the file if not already present
2. Wrap each signal calculation with timing:
   - `t_signal = time.perf_counter_ns()` before `signal_calc.calculate(...)`
   - `timing[signal_name] = time.perf_counter_ns() - t_signal` after
   - Add `timing['_total'] = time.perf_counter_ns() - t_start` after the loop
3. Add profiling counter to state: after `state.log_signal_normalize_add(record)`, increment `state._profiling_candle_count` (init to 0 if not exists using `getattr(state, '_profiling_candle_count', 0)`)
4. Every 100 candles, log summary:
   ```python
   if candle_count % 100 == 0:
       avg = {k: v/100/1_000_000 for k, v in timing.items()}
       logger.info(f"[PROFILING] [{symbol}] avg_ms={json.dumps(avg, default=str)}")
   ```
5. Push timing data to Redis stream `aureus:profiling:{symbol}` with maxlen=10000. Wrap in try/except so Redis failure never crashes the engine:
   ```python
   try:
       last_t = state.last_candle.get('t', 0)
       payload = {"t": str(last_t)}
       payload.update({k: str(v) for k, v in timing.items()})
       await redis_client.xadd(f"aureus:profiling:{symbol}", payload, maxlen=10000)
   except Exception as e:
       logger.warning(f"[PROFILING] Redis write failed: {e}")
   ```

The timing code MUST be placed so that:
- It does NOT wrap the `state.map_signal_to_candle_record()` call (only times signal calculation)
- It does NOT affect the return value or state mutation of the function
- The try/except around each signal calc (existing lines 95-108) remains — add timing INSIDE the try block, before the calculate call and after it

</action>
