<domain>
## Phase Boundary

Phase 44.0 adds profiling instrumentation to the signal engine to measure real CPU/memory/time per signal, per symbol, per candle over a 24h period. This is NOT an optimization phase — it is a measurement phase that provides data to prioritize subsequent optimization phases (44.1-44.5).

**What this phase delivers:**
- Timing instrumentation in `execute_signals_for_candle()` — per-signal nanosecond timing
- Timing instrumentation in `WindowManager.update()` — DataFrame build time, integrity check time
- Redis stream aggregation for profiling data (separate channel: `aureus:profiling:{symbol}`)
- Logging summary every 100 candles to avoid log spam
- No functional changes to signal calculation — purely additive instrumentation
- Zero risk to trading logic — instrumentation runs in parallel, never blocks or modifies signal output

**Out of scope:**
- Actual performance optimization (that's phases 44.1-44.5)
- UI/dashboard for profiling data (can be done later)
- Alerting/notification on slow signals
</domain>

<decisions>
## Implementation Decisions

### Instrumentation Location
- Instrument INSIDE `execute_signals_for_candle()` in `live_engine.py` (lines 85-112)
- Instrument INSIDE `WindowManager.update()` in `manager.py` (lines 85-142)
- Use `time.perf_counter_ns()` for nanosecond precision
- Log summary every 100 candles to avoid flooding logs

### Data Storage
- Store profiling data in Redis stream: `aureus:profiling:{symbol}`
- Each entry: `{t, signal_name, duration_ns, _total_ns}`
- Redis MAXLEN ~10000 per symbol to bound memory (≈10000 candles × ~15 signals × 8 bytes ≈ 1.2MB per symbol)

### Logging Frequency
- Log to console/file every 100 candles per symbol
- Format: `[PROFILING] [{symbol}] t={timestamp} avg_ms={signal_name: ms, ...} total_ms={total}`

### Safety Guards
- Instrumentation MUST NOT change signal calculation results
- Instrumentation MUST NOT block or slow down candle processing significantly (overhead < 0.1ms per candle)
- Instrumentation MUST be removable by reverting commits (no schema changes, no config changes)
- Use try/except around timing code — if timing fails, log warning but never crash

### Aggregation
- After 24h (or on-demand), aggregate profiling data to produce summary:
  - Per-signal avg/p95/p99 execution time
  - Per-symbol total candle processing time
  - DataFrame rebuild time vs signal calc time ratio
  - Warmup breakdown (DB fetch vs DataFrame vs signal calc)

### Decision: NO external dependencies
- Use only `time` module (stdlib) — no new pip packages
- Use existing Redis client — no new connections
- Use existing logger — no new logging infrastructure
</decisions>

<specifics>
## Specific Implementation Details

### Per-signal timing code pattern:
```python
def execute_signals_for_candle(signals, df, state, symbol, redis_client):
    t_start = time.perf_counter_ns()
    timing = {}

    for signal_name, signal_calc in signals.items():
        t_signal = time.perf_counter_ns()
        res = signal_calc.calculate(df, state, redis_client=redis_client, symbol=symbol)
        timing[signal_name] = time.perf_counter_ns() - t_signal

    timing['_total'] = time.perf_counter_ns() - t_start

    # Log every 100 candles
    candle_count = getattr(state, '_profiling_candle_count', 0) + 1
    state._profiling_candle_count = candle_count
    if candle_count % 100 == 0:
        avg = {k: v/100/1_000_000 for k, v in timing.items()}
        logger.info(f"[PROFILING] [{symbol}] avg_ms={avg}")

    # Push to Redis stream
    try:
        await redis_client.xadd(f"aureus:profiling:{symbol}",
            {"t": str(state.last_candle['t']), **{k: str(v) for k, v in timing.items()}},
            maxlen=10000)
    except Exception as e:
        logger.warning(f"[PROFILING] Redis write failed: {e}")
```

### WindowManager timing pattern:

```python
def update(self, symbol, data):

```

- 8 symbols × 1440 candles/day = 11,520 profiling entries
- Per entry: ~15 signal timings + total = ~16 data points
- Total: ~184K data points per day
- Redis memory: ~184K × 200 bytes ≈ 37MB per day (bounded by maxlen=10000 per symbol)
