## Testing Rules (Bắt Buộc)

Mọi test case trong phase này PHẢI tuân thủ 6 trụ cột dưới đây:

### 1. Inbound Test (Equivalence Partitioning)

**Mục đích:** Xác nhận code xử lý đúng các giá trị đầu vào hợp lệ được nhóm thành equivalence class.

**Áp dụng cho phase 38:**
- Valid `data` JSON string → unwrap thành công, order_data chứa đủ fields
- Valid `data` dict (không phải string) → unwrap thành công
- Payload không có `data` field → backward compat, dùng toàn bộ payload làm order_data
- Valid `status` values: `PENDING`, `SENT`, `FILLED`, `CLOSED` (state machine known values)
- Valid `open_time` types: `int`, `float`, `str` ISO format (mà `parse_ts()` chấp nhận)

**Rule:** Mỗi equivalence class PHẢI có ít nhất 1 test case.

### 2. Outbound Test (Boundary Value Analysis)

**Mục đích:** Xác nhận code xử lý đúng các giá trị tại biên của equivalence classes.

**Áp dụng cho phase 38:**
- `open_time`: `0`, `1`, max int (value > 100 năm từ nay)
- `entry_price`: `0.0`, `0.01` (min tick), max giá hợp lý (e.g., 99999.0)
- `trace_id`: empty string `""`, 1 char, max reasonable length, special characters (Unicode)
- `volume`: `None`, `0.0`, `0.01`, `100.0` (max lot)
- `data` field: empty JSON string `"{}"`, empty dict `{}`
- Envelope `type`: empty string `""`, unknown type `"UNKNOWN_TYPE"`, ORDER_REJECTED (edge case skip)

**Rule:** Mỗi boundary value PHẢI có test case riêng biệt, không group chung.

### 3. Black Box Test (Contract-Based)

**Mục đích:** Test từ góc độ external contract, không quan tâm implementation bên trong. Chỉ verify input → output đúng spec.

**Áp dụng cho phase 38:**
- Cho wrapped payload → DB có row mới với đúng cột trace_id, symbol, direction, entry_price, sl, tp, filled_at. Không check cách unwrap.
- Cho invalid payload → DB KHÔNG có row mới, event được ACK. Check hậu DB state, không check internal `rejected_msg_ids`.
- Cho ORDER_CLOSE → row existing được UPDATE status/CLOSED. Check DB query result.
- Cho ORDER_REJECTED → DB KHÔNG có thay đổi. Check no INSERT, no UPDATE.

**Rule:** Black box tests không được mock internal methods (không mock `_normalize_order_payload`). Chỉ test qua public interface `process_batch()`.

### 4. White Box Test (Internal Logic)

**Mục đích:** Test từng nhánh code path, bao phủ mọi nhánh condition. Phải biết implementation để viết assertions.

**Áp dụng cho phase 38:**
- Test `_normalize_order_payload()` trực tiếp: string data → `json.loads()`, dict data → pass-through, invalid JSON → `ValueError`, no data field → return payload. Gọi `_normalize_order_payload` trực tiếp.
- Test `process_batch()` order_buffer branch: trace_id None → skip + rejected_msg_ids.append, trace_id exists → state_machine.validate_transition() called, valid transition → INSERT query built, invalid transition → rejected_msg_ids.append. Gọi `process_batch` và check `db_writer.order_buffer`, `rejected_msg_ids`.
- Test timestamp validation branch: open_time None → rejected, open_time empty string → rejected, open_time valid → parse_ts called. Gọi `_normalize_order_payload` rồi verify open_time value.

**Rule:** White box tests PHẢI assert trên internal variables (`order_buffer`, `rejected_msg_ids`, `event_type`, `normalized`).

### 5. Abnormal Case Test (Negative/Edge)

**Mục đích:** Test behavior khi input sai format, dữ liệu corrupt, edge cases không mong đợi.

**Áp dụng cho phase 38:**
- `data` field là số nguyên `data: 12345` → TypeError/ValueError. Không crash, reject gracefully.
- `data` field là list `data: []` → not a dict → reject.
- `data` field là nested JSON sâu → vẫn parse đúng, không stack overflow.
- `data` field chứa JSON rất lớn (>1MB) → parse thành công hoặc reject với timeout/memory guard. Không crash.
- Payload là `None` → AttributeError nếu `payload.get()`. Must handle gracefully. Không crash.
- Payload không phải dict (string, list) → xử lý thế nào? Must not crash.
- `open_time` là string không phải ISO format → "not a date" → parse_ts xử lý hoặc reject không crash.
- `open_time` là negative number → `-1` → reject hoặc parse_ts trả về epoch. Không crash process.
- `trace_id` chứa SQL injection chars → `"'; DROP TABLE aureus_trades;--'"`. Parametrized query must handle, không SQL injection.
- `envelope` type là None → `payload.get('type', '')` returns "". Không crash, xử lý như unknown.
- Duplicate msg_id on stream → idempotency: không INSERT 2 rows cùng trace_id.
- ORDER_CLOSE khi chưa có ORDER_OPEN → state machine reject. Check no UPDATE performed.

**Rule:** Abnormal case test PHẢI verify: không exception uncaught, event được reject/gracefully skipped, log warning có lý do rõ ràng.

### 6. Code 100% Coverage (Line + Branch)

**Mục đích:** Đảm bảo mọi dòng code và mọi nhánh điều kiện trong code bị ảnh hưởng bởi phase này đều được test thực thi.

**Coverage targets:**
- File `services/aureus-db-writer/main.py`: coverage 100% cho order_buffer section (dòng ~451-620 sau sửa).
- Method `_normalize_order_payload` → 100% line coverage, 100% branch coverage (if/else, try/except).
- Timestamp validation block → 100% line, open_time None, empty, invalid, valid đều có test.
- State machine transition check → valid/invalid/unknown status đều có test.
- INSERT/UPDATE query building → các branches volume None/not-None, exit_price None/not-None.
- ACK flow → rejected_msg_ids populated, stream messages ACKed.

**Verification command:** `pytest --cov=services/aureus-db-writer.main --cov-report=term-missing services/aureus-db-writer/tests/test_order_buffer.py -x` → coverage 100% cho order_buffer lines.

**Rule:** Nếu coverage report show line/branch nào chưa được execute → PHẢI bổ sung test case cho line/branch đó trước khi merge.

```python
import json
import pytest

class TestWrappedPayloadUndoWrap:
    """Test that order_buffer correctly unwraps the 'data' field from producer envelope."""
    
    def test_unwrap_json_string_data(self, db_writer):
        """Verify trace_id is read from unwrapped data, not top-level."""
        order_data = {
            "trace_id": "XAUUSD:strat_001:1234567890",
            "symbol": "XAUUSD",
            "strategy_id": 1,
            "strategy_name": "TestStrat",
            "side": "BUY",
            "type": "MARKET",
            "entry_price": 2000.0,
            "sl": 1990.0,
            "tp": 2020.0,
            "status": "PENDING",
            "open_time": 1234567890,
            "close_time": None,
            "pnl": 0.0,
            "exit_price": None,
        }
        wrapped = {
            "type": "ORDER_OPEN",
            "data": json.dumps(order_data),
        }
        db_writer.order_buffer.append(("aureus:stream:XAUUSD:orders", "123456789-0", wrapped))
        # After process_batch, trace_id should be found (not None)
        # Assert: order was processed, no NameError, trace_id extracted
        event_type, normalized = db_writer._normalize_order_payload(wrapped)
        assert event_type == "ORDER_OPEN"
        assert normalized["trace_id"] == "XAUUSD:strat_001:1234567890"
        assert normalized["side"] == "BUY"
    
    def test_unwrap_dict_data(self, db_writer):
        """Verify data field as dict (not string) is handled."""
        order_data = {"trace_id": "EURUSD:strat_002:999", "symbol": "EURUSD", "side": "SELL", "type": "MARKET", "status": "PENDING", "open_time": 999999999, "entry_price": 1.08}
        wrapped = {"type": "ORDER_OPEN", "data": order_data}
        event_type, normalized = db_writer._normalize_order_payload(wrapped)
        assert event_type == "ORDER_OPEN"
        assert normalized["trace_id"] == "EURUSD:strat_002:999"
    
    def test_non_dict_data_raises(self, db_writer):
        """Verify non-dict data raises ValueError."""
        wrapped = {"type": "ORDER_OPEN", "data": "not a valid json"}
        with pytest.raises(ValueError, match="Failed to parse order data JSON"):
            db_writer._normalize_order_payload(wrapped)
    
    def test_no_data_field_backward_compat(self, db_writer):
        """Verify payload without 'data' field uses entire payload as order_data."""
        flat = {"trace_id": "TEST:flat:001", "symbol": "GBPUSD", "side": "BUY"}
        event_type, normalized = db_writer._normalize_order_payload(flat)
        assert normalized["trace_id"] == "TEST:flat:001"
        # event_type will be empty since flat dict has no 'type'
        assert event_type == ""
```

```python
class TestMissingTimestampRejection:
    """Test strict timestamp validation (D-06, D-07, D-08)."""
    
    def _make_order(self, **overrides):
        base = {
            "trace_id": "XAUUSD:strat:ts",
            "symbol": "XAUUSD",
            "side": "BUY",
            "type": "MARKET",
            "status": "PENDING",
            "entry_price": 2000.0,
            "sl": 1990.0,
            "tp": 2020.0,
            "open_time": 1234567890,
        }
        base.update(overrides)
        return {"type": "ORDER_OPEN", "data": json.dumps(base)}
    
    def test_missing_open_time_rejected(self, db_writer):
        wrapped = self._make_order()
        data = json.loads(wrapped["data"])
        del data["open_time"]
        wrapped["data"] = json.dumps(data)
        event_type, order_data = db_writer._normalize_order_payload(wrapped)
        assert order_data.get("open_time") is None
    
    def test_empty_open_time_rejected(self, db_writer):
        wrapped = self._make_order(open_time="")
        _, order_data = db_writer._normalize_order_payload(wrapped)
        assert order_data.get("open_time") == ""
    
    def test_none_open_time_rejected(self, db_writer):
        wrapped = self._make_order(open_time=None)
        _, order_data = db_writer._normalize_order_payload(wrapped)
        assert order_data.get("open_time") is None
    
    def test_valid_open_time_accepted(self, db_writer):
        wrapped = self._make_order(open_time=1234567890)
        _, order_data = db_writer._normalize_order_payload(wrapped)
```

```python
class TestCanonicalPayloadStorage:
    """Test that payload column stores canonical data, not raw envelope (D-11)."""
    
    def test_wrapped_payload_canonical_storage(self, db_writer):
        order_data = {
            "trace_id": "XAUUSD:test:canonical",
            "symbol": "XAUUSD",
            "side": "SELL",
            "type": "MARKET",
            "status": "PENDING",
            "open_time": 1234567890,
            "entry_price": 2000.0,
        }
        wrapped = {"type": "ORDER_OPEN", "data": json.dumps(order_data)}
        
        # After normalization, stored payload should be order_data, not wrapped
        _, normalized = db_writer._normalize_order_payload(wrapped)
        stored = json.dumps(normalized)
        stored_dict = json.loads(stored)
        
        # Should NOT have envelope 'data' key
        assert "data" not in stored_dict or isinstance(stored_dict.get("data"), dict)
        assert stored_dict["trace_id"] == "XAUUSD:test:canonical"

        # The normalized payload should be the inner dict, not the envelope
        assert normalized.get("trace_id") == "X"
```
