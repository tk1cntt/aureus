# Phase 15.10: Pydantic Signal History Refactoring

**Goal:** Chuyển đổi cấu trúc dữ liệu `signal_history` từ `List[Dict]` sang sử dụng các Data Models có kiểu dữ liệu chặt chẽ (Pydantic `BaseModel`) hỗ trợ Đa hình (Polymorphism) để phục hồi và xử lý an toàn.
**Requirements**: Refactor schema for better type-safety and maintainability.
**Depends on:** Phase 15.9

## 1. Thiết kế Schema Pydantic (`signal.py`)
Tạo file `services/aureus-signal/engine/models/signal.py` chứa:
- `BaseSignalRecord`: `category`, `tag`, `t`, `explain`, `price` (gộp chung pivot_price và target_price)
- Các kế thừa: 
  - `StructureSignalRecord` (`category="structure"`, `is_bullish`, `breakout_t`, `ob_data`)
  - `EMASignalRecord` (`category="ema"`, `ema_period`, `slope`)
  - `TrendSignalRecord` (`category="trend"`, `regime`, `ema_ref`, `bullish_ob_count`, `bearish_ob_count`)
  - `SessionSignalRecord` (`category="session"`, `session_name`, `broker_time`, `user_time`)
  - `LiquiditySignalRecord` (`category="liquidity"`, `status`, `ob_type`, `mitigated`)
  - `ImbalanceSignalRecord` (`category="imbalance"`, `direction`, `top`, `bottom`)
  - `StrategySignalRecord` (`category="strategy"`, `strategy`, `status`)
- Collection: `SignalHistoryList` wrapper để dùng cho Deserialize validation với discriminator `category`.

## 2. Refactor Signal Context (`state.py` & Consumers)
- **`state.py`**: Chỉnh sửa signature `log_signal` để nhận `BaseSignalRecord`. Nếu truyền dict (do legacy backtest), convert sang tương thích.
- **`ai_validator.py`**: Thay thế toàn bộ các dict property access (`.get("tag")`) thành object access (`.tag`, `.price`...).

## 3. Refactor Signal Calculators (`engine/signals/*.py`)
- Thay thế các đoạn code `return { "tag": ... }` trong các hàm `calculate()`:
  - `ema.py` -> trả về `EMASignalRecord`
  - `trend.py` -> trả về `TrendSignalRecord`
  - `structure.py` -> trả về `StructureSignalRecord`
  - `session.py` -> trả về `SessionSignalRecord`
  - `sweep.py` -> trả về `LiquiditySignalRecord`
  - `fvg.py` -> trả về `ImbalanceSignalRecord`

## 4. Refactor Deserialization (`state_snapshot.py`)
- Trong `restore_to_state`, sử dụng tính năng Pydantic Validation (`SignalHistoryList.model_validate`) để chuyển đổi danh sách JSON flat dictionary thành mảng Strongly-typed instances.

## 5. Verification
- Chạy `python -m py_compile` toàn bộ code sửa đổi.
- Run backtest smoke test logic mapping.
- Kiểm tra Pydantic validation trên một snapshot JSON giả định.
