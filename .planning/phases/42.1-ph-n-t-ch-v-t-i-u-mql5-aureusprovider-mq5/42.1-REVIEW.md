## Warnings

### WR-01: Parse JSON thủ công dễ fail khi payload có khoảng trắng/format khác

**File:** `mql5/AureusProvider.mq5:492-503`
**Issue:** `ParseJSONString()` tìm đúng chuỗi `"key":"` nên sẽ fail nếu command JSON hợp lệ nhưng có whitespace (`"key" : "value"`) hoặc thứ tự/format khác. Khi fail, `cmdSymbol` rỗng và logic có thể áp dụng backfill cho toàn bộ symbol thay vì symbol mục tiêu.
**Fix:** Dùng parser JSON thực thụ (nếu có trong runtime/library) hoặc parse key/value linh hoạt hơn (bỏ qua whitespace). Ví dụ tối thiểu:
```cpp
string ParseJSONStringLoose(const string &raw, const string key)
{
   string k = "\"" + key + "\"";
   int kpos = StringFind(raw, k);
   if(kpos < 0) return "";

   int colon = StringFind(raw, ":", kpos + StringLen(k));
   if(colon < 0) return "";

   // skip spaces
   int i = colon + 1;
   while(i < StringLen(raw) && (StringGetCharacter(raw, i) == ' ')) i++;
   if(i >= StringLen(raw) || StringGetCharacter(raw, i) != '"') return "";

   int start = i + 1;
   int end = StringFind(raw, "\"", start);
   if(end < 0) return "";
   return StringSubstr(raw, start, end - start);
}
```

### WR-02: Log “complete” không phản ánh số nến thực sự đã gửi khi send fail giữa chừng

**File:** `mql5/AureusProvider.mq5:382-407, 431-455`
**Issue:** Trong cả `DoBackfillForSymbol()` và `DoBackfillCountForSymbol()`, nếu `SendJSON` fail ở giữa vòng lặp, hàm vẫn in log `... complete: <filteredCount|copied> candles sent` thay vì số đã gửi thành công. Điều này gây lệch telemetry vận hành và che khuất lỗi truyền dữ liệu.
**Fix:** Theo dõi biến `sentCount` và log theo số thực tế đã gửi thành công.

```cpp
...

```
