# Phase 21.2 Plan: Patch TradingAgents Source Code for LLM Proxy Support

## Objective
The `PAUSE_AND_PIVOT` decision in Phase 21 was triggered because the `TradingAgents` framework rigidly routes `ChatOpenAI` traffic directly to `platform.openai.com` (using the `/v1/responses` API) when configured for OpenAI, ignoring the custom `OPENAI_API_BASE` proxy configuration. 

We will patch the cloned source code of `TradingAgents` to conditionally disable `use_responses_api` if a custom proxy (`base_url`) is provided. This will default the client to standard `v1/chat/completions` which passes cleanly through reverse proxies. Then, update the Docker setup to build using the local source rather than fetching from GitHub, and re-test.

## must_haves
1. Search and patch `use_responses_api = True` logic in `openai_client.py`.
2. Update `requirements.txt` and `Dockerfile` to install the local `TradingAgents` package instead of pulling from GitHub.
3. Re-run the Docker validations to evaluate if proxy queries succeed.
4. Conclude the compatibility report explicitly based on new test outcomes.

## Task 1: Patch `openai_client.py` in TradingAgents

<read_first>
- services/aureus-trading-agents/TradingAgents/tradingagents/llm_clients/openai_client.py
</read_first>

<action>
1. Locate the following code block in `services/aureus-trading-agents/TradingAgents/tradingagents/llm_clients/openai_client.py`:
   ```python
   # Native OpenAI: use Responses API for consistent behavior across
   # all model families. Third-party providers use Chat Completions.
   if self.provider == "openai":
       llm_kwargs["use_responses_api"] = True
   ```
2. Modify the condition to only enforce Responses API if a custom `base_url` is *not* set. If `base_url` is set, we assume we're running behind a local/proxy layer that relies on standard Chat Completions.
   ```python
   # Native OpenAI: use Responses API for consistent behavior across
   # all model families. Third-party providers use Chat Completions.
   if self.provider == "openai" and not self.base_url:
       llm_kwargs["use_responses_api"] = True
   ```
3. Commit the change locally to the TradingAgents sub-repository.
</action>

<acceptance_criteria>
