<code_context>
## Current Code Facts (validated)

- `sweep.py` cập nhật state OB trong `_update_ob_states()` rồi emit tối đa 1 sweep event / candle.
- User đã đổi terminal sweep state từ `DEAD` sang `CLEAN_BREAKOUT` trong state machine (`_update_ob_states`).
- User đã cập nhật mitigation gate tại `SweepSignal.calculate`:
  - Nếu `mitigated=True`, event chỉ hợp lệ khi `0 < (c_t - t_mitigation) <= 300` giây.
  - Nếu thiếu/invalid `t_mitigation` thì skip emit.
- `STRUCTURAL_TAGS` hiện dùng canonical tags (`sweep_bull/bear`, `stop_hunt_*`, `clean_breakout_*`, `sweep_broken_pending_*`, `sweep_touched_*`) và bỏ alias cũ kiểu `sweep_swept_*`, `sweep_dead_*`.
- `_AI_TAG_TO_TRIGGER` đã bỏ map cho `sweep_touched_bull/bear`; các trigger sweep đang còn `sweep_bull/bear`, `stop_hunt_*`, `clean_breakout_*`, `sweep_broken_pending_*`.
- `live_engine.py` gọi `evaluate_ai_trigger_events(state.transient_signals)` mỗi candle để append `ai_trigger_events`.
- `analysis['sentiment']` trong pulse được lấy trực tiếp từ `AIBrainClient.generate_pulse()` output.
- `_AI_TAG_TO_TRIGGER` chỉ đảm nhiệm mapping trigger/context cho event queue, không ép sentiment hậu xử lý.

</code_context>

<decisions>
## Final Decisions

### D-01 — Sweep detected rules
- **Decision:** Áp dụng rule state-aware cho sweep events trong `SweepSignal`.
- **Result:** Đã triển khai và verify bằng test sweep.

### D-02 — `missing origin_timestamp` warning
- **Decision:** Chốt root-cause ở live path: giá trị timestamp có thể tồn tại key nhưng `None`, làm fallback hiện tại không kích hoạt như kỳ vọng.
- **Result:** Đã hoàn tất phân tích call-path và ghi nhận nguyên nhân để xử lý ở phase tương ứng.

### D-03 — Sentiment mapping via `_AI_TAG_TO_TRIGGER`
- **Decision:** Không thay đổi logic sentiment hiện tại.
- **Reason:** Sentiment là output dự đoán từ AI model; trigger mapping chỉ dùng cho ngữ cảnh/event queue.
- **Result:** Kết thúc bằng quyết định giữ nguyên hành vi runtime.

### D-04 — Logging hot-reload
- **Decision:** Hoàn tất cơ chế auto-refresh logging settings để không cần restart service.
- **Result:** Đã triển khai + test xác nhận.

### D-05 — Mitigation age gate refinement (user patch)
- **Decision:** Chốt gate mới: mitigated event chỉ emit khi `0 < age <= 300s`.
- **Result:** Đã cập nhật trực tiếp trong `sweep.py` bởi user, phase docs đồng bộ theo hành vi mới.

### D-06 — Sweep lifecycle/tag rename alignment (user patch)
- **Decision:** Đồng bộ toàn hệ về naming mới `CLEAN_BREAKOUT` và dọn alias tags cũ trong filter/policy.
- **Result:** Retest pass (`event_filter` + sweep suites) sau khi cập nhật 1 assertion test còn dùng alias `sweep_swept_bull`.

</decisions>
