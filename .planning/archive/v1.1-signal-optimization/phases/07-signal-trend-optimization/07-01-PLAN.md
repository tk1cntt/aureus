# Phase 07, Plan 01: Implement OB-Dominance Matrix in Trend Signal

## Objective
Replace the obsolete EMA slope logic in `trend.py` with the "Unmitigated OB Matrix" detailed in `07-CONTEXT.md` and `07-RESEARCH.md`.

## Execution Steps

### Step 1. Update `trend.py` Algorithm
**File:** `services/aureus-signal/engine/signals/trend.py`
- Modify `TrendSignal.calculate()` to extract `state_obj.obs` (default to `[]` if missing).
- Count unmitigated OBs grouped by `BULLISH` and `BEARISH` (`ob_type`).
- Check current price against `EMA 200`.
- Apply Matrix Logic rules:
  - If `green >= 2` AND `red >= 2`: `SIDEWAYS` / `NEUTRAL`
  - Elif `green - red >= 2` AND `current_price > current_ema`: `TREND_UP` / `BULLISH`
  - Elif `red - green >= 2` AND `current_price < current_ema`: `TREND_DN` / `BEARISH`
  - Else: `SIDEWAYS` / `NEUTRAL`
- Update the returned dict to remove `slope` and add `green_ob_count`, `red_ob_count`, and `delta`.

### Step 2. Update/Create Unit Tests
**File:** `services/aureus-signal/tests/test_trend_o1.py` (create new or edit existing)
- Add mock tests representing the 4 scenarios (Sideways, Trend Up, Trend Down, Divergence).
- Add test showing mitigated OBs are correctly skipped.
- Fix any broken assertions in legacy tests relying on the `slope` key.
