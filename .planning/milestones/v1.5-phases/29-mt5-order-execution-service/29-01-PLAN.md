# Plan 29-01: aureus-trader Service — Order Execution Pipeline

<objective>
Build the `aureus-trader` microservice that subscribes to Redis `aureus:signals:{symbol}` channels, filters STRATEGY_MATCH events, validates and converts them to OPEN_ORDER commands, queues them in a Redis List for resilience, dispatches to MT5 via `aureus:mt5:commands`, and tracks ACK/NACK + ORDER_OPENED/ORDER_FAILED responses with selective retry logic.
</objective>

<must_haves>
- aureus-trader service subscribes to Redis pub/sub and receives STRATEGY_MATCH events (ORDER-01)
- Market orders are correctly built and sent to MT5 via Redis publish (ORDER-02)
- Pending orders (LIMIT/STOP) are correctly built and sent to MT5 (ORDER-03)
- Hash-based idempotency key prevents duplicate order execution (ORDER-07)
- Redis List order queue persists pending orders across service restarts
- Selective retry for retryable errors with exponential backoff (max 3 retries)
- Docker container runs in docker-compose.dev.yml
</must_haves>

Create `services/aureus-trader/idempotency.py` with:

1. **Class `IdempotencyChecker`:**
   ```python
   class IdempotencyChecker:
       def __init__(self, redis_client, ttl: int = 86400):
           self.redis = redis_client
           self.ttl = ttl
       
       async def is_duplicate(self, cmd_id: str) -> bool:
           """Check if cmd_id was already processed."""
           key = f"aureus:trader:dedup:{cmd_id}"
           return await self.redis.exists(key) > 0
       
       async def mark_processed(self, cmd_id: str) -> None:
           """Mark cmd_id as processed with TTL expiry."""
           key = f"aureus:trader:dedup:{cmd_id}"
           await self.redis.set(key, "1", ex=self.ttl)
       
       async def check_and_mark(self, cmd_id: str) -> bool:
           """Atomic check-and-mark. Returns True if NEW (not duplicate)."""
           key = f"aureus:trader:dedup:{cmd_id}"
           # SET with NX returns True only if key was set (new)
           result = await self.redis.set(key, "1", ex=self.ttl, nx=True)
           return result is not None
   ```

   Key design:
   - Uses Redis `SET ... EX ... NX` for atomic check-and-mark (race-condition safe)
   - TTL 24h per 29-CONTEXT.md D-02
   - Key format: `aureus:trader:dedup:{cmd_id}`
</action>

   - Loop while `_running`

   **`async def dispatch_order(self, order: dict)`**:
   Per 29-CONTEXT.md D-03:
   ```python
   for attempt in range(self.config.max_retries + 1):
       # PUBLISH to aureus:mt5:commands
       await self.redis.publish("aureus:mt5:commands", json.dumps(order))
       
       # Wait for ACK/NACK (5s timeout)
       ack_result = await self._wait_for_response(order["cmd_id"], self.config.ack_timeout)
       
       if ack_result is None:  # timeout
           logger.warning(f"ACK timeout for {order['cmd_id']}, attempt {attempt+1}")
           if attempt < self.config.max_retries:
               await asyncio.sleep(2 ** attempt)
               continue
           else:
               await self._handle_max_retries(order)
               return
       
       if ack_result["type"] == "NACK":
           if is_retryable(ack_result):
               await asyncio.sleep(2 ** attempt)
               continue
           else:
               await self._handle_rejection(order, ack_result)
               return
       
       if ack_result["type"] == "ACK":
           # Wait for ORDER_OPENED/FAILED (30s timeout)
           final = await self._wait_for_response(order["cmd_id"], self.config.result_timeout)
           if final and final["type"] == "ORDER_OPENED":
               logger.info(f"Order executed: {order['cmd_id']} ticket={final.get('ticket')}")
               return
           elif final and is_retryable(final):
               await asyncio.sleep(2 ** attempt)
               continue
           elif final:
               await self._handle_rejection(order, final)
               return
           else:
               logger.warning(f"Result timeout for {order['cmd_id']}")
               await self._handle_max_retries(order)
               return
   
   await self._handle_max_retries(order)
   ```

   **`async def event_listener(self)`**:
   Subscribe to `aureus:mt5:events`, parse JSON events, match by `cmd_id` to resolve pending futures in `_pending_responses`.

   **`async def _wait_for_response(self, cmd_id: str, timeout: float) -> dict | None`**:
   Create `asyncio.Future`, register in `_pending_responses[cmd_id]`, await with timeout. Return event dict or None on timeout.

   **`async def _handle_rejection(self, order: dict, event: dict)`**:
   Log rejection, publish ORDER_REJECTED alert to `aureus:signals:{symbol}`.

   **`async def _handle_max_retries(self, order: dict)`**:
   Log max retries exceeded, publish ORDER_REJECTED alert to `aureus:signals:{symbol}`.
