# Phase 44.0 Validation — Profiling Baseline Performance

Mục tiêu: xác nhận phase 44.0 hoàn tất đúng phạm vi baseline profiling (đo lường), không lẫn optimization logic structure.

## Requirement Coverage

| Requirement | Validation command | Expected evidence |
|---|---|---|
| PROF-01 (instrument timing) | `pytest services/aureus-signal/tests/test_profiling_instrumentation.py -k "signal_results or profiling_records_timing" -q -x` | Có timing per-signal + `_total` và kết quả signal không đổi |
| PROF-02 (log aggregation) | `pytest services/aureus-signal/tests/test_profiling_instrumentation.py -k "logs_every_100_candles or redis_failure" -q -x` | Có log `[PROFILING]` mỗi 100 candles; Redis lỗi không crash |
| PROF-03 (bottleneck identification) | `pytest services/aureus-signal/tests/test_profile_summary.py -q -x` | Summary có `avg/p95/p99`, `symbol_totals`, `bottleneck_ranking`, `ratio_df_vs_signal` |

## Full Phase Check

1. `pytest services/aureus-signal/tests/test_profiling_instrumentation.py -q -x`
2. `pytest services/aureus-signal/tests/test_profile_summary.py -q -x`

Pass condition:
- Tất cả command pass.
- Không có thay đổi file optimization path (`structure.py`, `structure_opt.py`, `structure_parity.py`) trong phase 44.0.
- Output summary có dữ liệu đủ để chọn ưu tiên phase 44.1+.

## Scope Guard

Các mục sau phải **không xuất hiện** trong implementation phase 44.0:
- Thay đổi thuật toán StructureSignal.
- Dual-path shadow optimization rollout (off/shadow/on).
- Module optimization mới cho structure logic.

Nếu xuất hiện các mục trên: FAIL vì lệch scope phase 44.0.
