<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web client → performance API | Query params từ client là input không tin cậy |
| performance API → Redis cache | Dữ liệu cache có thể stale nếu key semantics không đồng nhất |
| performance API → PostgreSQL | Query/filter sai có thể trả dữ liệu sai phạm vi |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01 | T | `/api/v1/performance/*` query parser | mitigate | Validate tập trung cho page/page_size/status/date/timeframe; reject 4xx structured error thay vì fallback |
| T-48-02 | I | metrics/equity cache key | mitigate | Đồng nhất dimensions filter trong cache key + giảm TTL khi cần để tránh split-brain |
| T-48-03 | D | trades endpoint pagination | mitigate | Hard limit page_size theo allowlist + deterministic sort để tránh re-fetch loop và churn |
| T-48-04 | R | invalid filter handling | mitigate | Trả error envelope ổn định có code/message/details để client và log đối soát chính xác |
</threat_model>
