## 📋 Executive Summary

### The Problem

Strategies stop triggering after running for a while (typically 4-8 hours). Service does NOT crash — it runs normally, processes candles, receives stream messages. But **every strategy evaluation returns SEQUENCE_NOT_MATCHED** until service restart.

**User workaround:** Restart service → works again for 4-8 hours → dies again

### Root Cause Analysis

Phase 39.1 Plans 01-03 fixed **mid-sequence stalls** but missed the CRITICAL **post-trigger stall**:

```
1. Strategy triggers → triggered_t = bar_t (e.g., 1775850000)
2. Next candle → ALL events have t <= triggered_t → SKIPPED
3. Auto-reset check: if current_step_index > 0 → FALSE (it's 0 after trigger)
4. Result: SEQUENCE_NOT_MATCHED forever ← THIS IS THE BUG
```

## 🎯 Stage 1: Fix Post-Trigger Stall (Plan 04)

### Why This Is URGENT

**This is the root cause** of why strategies die after running for a while. Plans 01-03 only fixed mid-sequence stalls, not post-trigger stalls.

### Implementation Overview

**File:** `services/aureus-signal/engine/strategies/template.py`

**Change 1:** In `_reset_sequence_state`, save `_trigger_candle_counter`:
```python
"_trigger_candle_counter": internal_candle_counter,  # ADD THIS
```

**Change 2:** In `_evaluate_sequence`, add timeout check after `internal_candle_counter += 1`:
```python
if triggered_t > 0 and current_step_index == 0:
    candles_since_trigger = internal_candle_counter - state.get("_trigger_candle_counter", 0)
    if candles_since_trigger > 10:
        triggered_t = 0  # Clear to allow new events
```

### Tests (3 new)

1. **test_trigger_timeout_clears_after_n_candles** — Verify timeout fires after 10 candles
2. **test_no_double_trigger_within_timeout_window** — Verify no double-trigger within 10 candles
3. **test_can_trigger_again_after_timeout_expires** — Verify can trigger again after timeout

### Expected Outcome

- ✅ Strategies no longer stall permanently after first trigger
- ✅ Can trigger multiple times without restart
- ✅ 10-candle timeout prevents immediate re-triggering (safety)

### Risk Assessment

**Risk:** LOW — Additive change only, ~15 lines of code  
**Rollback:** Change 200 back to 500 if needed (1 line)  
**Blast Radius:** LOW — Only affects `_evaluate_sequence` method

### Why This Is Needed

Stages 1-2 fix known stall patterns, but future unknown issues could still cause silent failures. Health monitoring:
- **Early warning** when no triggers for 1+ hour
- **Diagnostics** showing which strategies are stuck
- **Self-healing** without manual restart

### Implementation Overview

**File:** `services/aureus-signal/engine/strategy_executor.py`

**Add before main loop:**
```python
last_trigger_time = time.time()
health_check_interval = 60  # Check every 60s
stall_threshold = 3600  # 1 hour without triggers
```

**Add inside main loop (periodic check):**
```python
if time_since_last_trigger > stall_threshold:
    logger.warning("[HEALTH] No triggers in 1h, possible stall")
    # Log diagnostics for each stuck strategy
    # Self-heal: clear triggered_t for all stuck strategies
```
