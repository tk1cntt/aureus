```python
def log_signal_normalize_add(self, record: CandleRecord) -> None:
    payload = record.to_dict() if isinstance(record, CandleRecord) else record
    if not isinstance(payload, dict):
        return

    signals = payload.get("signals") if isinstance(payload.get("signals"), dict) else {}
    if not signals:
        return

    self.log_signal_normalize.append(payload)

    # Phase 39.1 Stage 2: Adaptive truncate based on strategy requirements
    # Default to 200 if no strategy context available (conservative)
    # If strategy sequence length known, use max(sequence * 3, 100)
    adaptive_max = 200
    strategy = getattr(self, '_current_evaluating_strategy', None)
    if strategy and hasattr(strategy, 'sequence'):
        seq_len = len(getattr(strategy, 'sequence', []))
        adaptive_max = max(seq_len * 3, 100)

    if len(self.log_signal_normalize) > adaptive_max:
        self.log_signal_normalize.pop(0)
```

**Alternative (simpler, recommended for Stage 2a):**

Since `_current_evaluating_strategy` is not available in state.py context (state is per-symbol, not per-strategy), use a simpler approach:

```python
def log_signal_normalize_add(self, record: CandleRecord) -> None:
    payload = record.to_dict() if isinstance(record, CandleRecord) else record
    if not isinstance(payload, dict):
        return

    signals = payload.get("signals") if isinstance(payload.get("signals"), dict) else {}
    if not signals:
        return

    self.log_signal_normalize.append(payload)

    # Phase 39.1 Stage 2: Reduced fixed limit (safe because Stage 1 timeout prevents stalls)
    # Reduced from 500 to 200 — still provides ample context for 3-5 step sequences
    # On M15: 200 candles = 50 hours of history (plenty for matching)
    if len(self.log_signal_normalize) > 200:
        self.log_signal_normalize.pop(0)
```

**Decision:** Use the simpler fixed 200 limit (Stage 2a) because:
1. State object doesn't have access to current strategy being evaluated
2. 200 is still conservative (50h on M15, 200h on H1)
3. Can implement true adaptive sizing later if needed (Stage 2b)
4. Lower risk, simpler implementation
