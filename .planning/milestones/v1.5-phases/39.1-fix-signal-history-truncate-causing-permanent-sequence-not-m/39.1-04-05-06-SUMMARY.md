## 📊 Summary

### Problem Solved

Strategies stop triggering after running for 4-8 hours. Service doesn't crash — it runs normally but every strategy evaluation returns `SEQUENCE_NOT_MATCHED` until manual service restart.

### Root Cause

Phase 39.1 Plans 01-03 fixed **mid-sequence stalls** but missed **post-trigger stalls**:
- After strategy triggers, `triggered_t` is set to block re-processing old events
- Auto-reset only fires when `current_step_index > 0` (mid-sequence)
- Post-trigger: `current_step_index == 0` → auto-reset NEVER fires → permanent stall
