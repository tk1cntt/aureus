# Phase 34: Fix SL TP calculation decimals and MT5 comment strategy name

## Objective
Correct the hardcoded point calculation in SL/TP parsing to use symbol-specific points, and fix the MT5 order comment to display the string `strategy_name` instead of `strategy_id`.

## Tasks

<task>
<title>Extract dynamic point size calculation helper</title>
<read_first>
- services/aureus-signal/engine/orders.py
</read_first>
<action>
In `services/aureus-signal/engine/orders.py`, add a module-level helper function `def get_point_size(symbol: str) -> float:` that returns the point multiplier for standard symbol formats:
- If 'JPY' in symbol -> return 0.001
- If 'XAU' in symbol or 'XAG' in symbol or 'GOLD' in symbol or 'SILVER' in symbol -> return 0.01
- If 'BTC' in symbol or 'ETH' in symbol -> return 0.01
- If 'SPX' in symbol or 'US30' in symbol or 'NDX' in symbol or 'NAS' in symbol or 'DJI' in symbol -> return 0.1
- else -> return 0.00001 (standard forex)
</action>
<acceptance_criteria>
- `services/aureus-signal/engine/orders.py` contains `def get_point_size(symbol: str) -> float:`
- The function correctly maps 'XAU' to `0.01` and default to `0.00001`.
</acceptance_criteria>
</task>

<task>
<title>Refactor _calculate_sl_tp to use dynamic point sizes</title>
<read_first>
- services/aureus-signal/engine/orders.py
- services/aureus-signal/engine/simulated_orders.py
</read_first>
<action>
In `services/aureus-signal/engine/orders.py` and `services/aureus-signal/engine/simulated_orders.py` (if it contains an identical `_calculate_sl_tp` method):
Update the `_calculate_sl_tp` method.
Find the `FIXED_PIPS` calculations for both SL and TP (e.g. `pips = raw_value / 100.0` or `pips = raw_value / 10000.0` and `buffer = sl_cfg.get('buffer', 0) / 10000.0`).
Replace the hardcoded division logic with:
```python
point_size = get_point_size(state_obj.symbol)
price_delta = raw_value * point_size
```
Apply this `price_delta` where it currently uses `pips`. (e.g. `sl = (entry - price_delta) if 'BUY'...`). Do the same for TP `FIXED_PIPS` logic and for the `SIGNAL_LOW`/`SIGNAL_HIGH` buffer logic: `buffer_price = buffer_val * point_size` instead of `/ 10000.0`.
Make sure you import or duplicate the `get_point_size` helper if `simulated_orders.py` doesn't reside in `orders.py` (or better, import it into `simulated_orders.py` from `engine.orders`).
</action>
<acceptance_criteria>
- `_calculate_sl_tp` in `orders.py` and `simulated_orders.py` does not contain `10000.0` or `100.0`.
- Instead, it uses `get_point_size(state_obj.symbol)` to calculate the `price_delta` and `buffer_price`.
- `grep "10000.0" services/aureus-signal/engine/orders.py` returns no matches inside `_calculate_sl_tp`.
</acceptance_criteria>
</task>
