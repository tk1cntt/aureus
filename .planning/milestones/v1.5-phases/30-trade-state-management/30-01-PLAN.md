<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Redis Stream → DB Writer | Untrusted order events from multiple sources (EA, trader, manual) |
| DB Writer → TimescaleDB | Validated data, but SQL injection via malformed payload fields |
| State Machine → DB Write | Invalid state transitions must be rejected before persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-01 | Tampering | order_buffer payload parsing | mitigate | Validate trace_id is non-empty TEXT, symbol is non-empty, direction IN ('BUY','SELL'), status IN allowed states before DB write |
| T-30-02 | Repudiation | Missing state transition validation | mitigate | validate_transition() rejects invalid transitions, logs warning with trace_id + attempted transition for audit trail |
| T-30-03 | Information Disclosure | JSONB payload in aureus_trades | accept | Payload contains order event data only (no PII, no credentials), low-value target |
| T-30-04 | Denial of Service | Redis stream flood with invalid orders | mitigate | BATCH_SIZE (50) + BATCH_TIMEOUT_MS (1000) rate limits processing, invalid messages skipped + logged (not ACKed) |
| T-30-05 | Elevation of Privilege | SQL injection via order event fields | mitigate | All parameters passed as positional args ($1, $2...) to asyncpg.executemany, never string-interpolated |
</threat_model>
