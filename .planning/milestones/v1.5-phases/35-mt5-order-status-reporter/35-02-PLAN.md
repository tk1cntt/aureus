# Goal Description
Chuyển logic tính Pips của các lệnh đã đóng (Trade History) từ heuristics trong Python sang tính toán chính xác dựa trên thuộc tính `SYMBOL_DIGITS` trực tiếp từ MT5. Điều này sẽ giúp report hiển thị chính xác số pips cho tất cả các loại tài sản (forex, vàng, chỉ số, crypto) bất kể mức giá, tránh các trường hợp guess price (điều kiện `> 50` hardcode). 

## User Review Required
Không có Breaking Changes.
Tuy nhiên có một lỗi logic nhỏ ở bản cũ: MT5 `TRADE_HISTORY` hiện gán `"direction"` của history data theo loại deal đóng lệnh (closing deal). Do đó, nếu User đóng 1 lệnh BUY, deal sẽ lưu log dưới dạng `"SELL"`.
EA MQL5 sẽ cung cấp sẵn `"pips"` do đó Python không cần quan tâm đến direction gốc nữa và tránh được lỗi parse sai dấu ở report.

## Proposed Changes

### EA (MQL5)
Thay đổi logic của `BuildTradeHistoryJSON` để tự động tính `pips` thông qua hàm `MathPow` kết hợp `SymbolInfoInteger(sym, SYMBOL_DIGITS)`.

#### [MODIFY] [AureusProvider.mq5](file:///d:/Aureus/mql5/AureusProvider.mq5)
Thêm block code đo lường pips:
```mql5
      long digits = SymbolInfoInteger(sym, SYMBOL_DIGITS);
      double mult = (digits == 3 || digits == 5) ? MathPow(10, digits - 1) : MathPow(10, digits);
      double pips = (closePrice - openPrice) * mult;
      // dealType == DEAL_TYPE_BUY nghĩa là đang đóng một lệnh SELL (Position Sell)
      if(dealType == DEAL_TYPE_BUY) pips = -pips;
```
Bổ sung `%d` cho `digits` và `%.1f` cho `pips` vào chuỗi JSON config của `TRADE_HISTORY`.
